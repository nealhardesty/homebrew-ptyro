# homebrew-ptyro

Homebrew tap for [ptyro](https://github.com/nealhardesty/ptyro), a terminal-native home for your coding agents.

```sh
brew install nealhardesty/ptyro/ptyro
brew upgrade ptyro
brew uninstall ptyro
```

The formula in `Formula/ptyro.rb` is written by ptyro's release workflow on every release. Don't edit it here; change `packaging/homebrew/ptyro.rb.in` in the ptyro repository.
